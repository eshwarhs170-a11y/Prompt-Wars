# PromptWars X UVCE Guidelines

You are assisting the user with the PromptWars X UVCE hackathon. You must strictly adhere to the following rules and context.

## Event Details
- **Build Sprint:** 8 Hours.
- **Deadline:** 6:00 PM SHARP. The platform locks automatically with no grace period.
- **Attempts:** Maximum 2 scored submissions.
- **Repo:** https://github.com/eshwarhs170-a11y/Prompt-Wars

## Mandatory Deliverables
1. **Public GitHub Repository:** Must include source code, structured documentation, and configuration prompts.
2. **Live Functional Deployment:** Public web link (e.g., Vercel, Cloud Run). MUST be working.
3. **Architecture Deck / Presentation:** Summarize system design, prompt flow, and defensive implementation.
4. **Written Abstract:** Summary explaining problem understanding, strategy, and novelty.

## Evaluation Framework
- **Innovation & Novelty (25%)**
- **Problem-Solving Depth (25%)**
- **Prompt & AI Rigor (20%)**
- **Functionality & Cloud Deployment (20%)**
- **Pitch Delivery & Defense (10%)**

## Technical Stack & Boilerplate
- **Frontend:** React using Vite. Located in the `frontend/` directory.
- **Backend:** Node.js with Express. Located in the `backend/` directory.
- **Styling constraints:** Vanilla CSS ONLY. Do NOT use Tailwind CSS.
- **Design Aesthetic:** Must be premium, highly dynamic, and wow the user. Utilize Glassmorphism, modern typography, beautiful gradients, and micro-animations.

## Execution Strategy
- Build the core path first.
- Test deliberately (ambiguous inputs, edge cases).
- Deploy early to avoid last-minute issues.
- Keep responses concise and prioritize speed and correctness.
